# Musik latar

Taruh file musik (.mp3, idealnya di bawah 3 MB) di folder ini, lalu isi di data undangan:

```js
music: '/assets/audio/nama-lagu.mp3',
```

Gunakan hanya musik yang boleh Anda pakai (bebas royalti atau berlisensi).
Tombol musik otomatis muncul bila `music` diisi, dan tersembunyi bila kosong.
